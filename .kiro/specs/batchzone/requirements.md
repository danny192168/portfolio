# Batchzone Code Specification

Batchzone is the third `.project-card` in the Projects section. Its markup uses
`data-project="batchzone"` and indices `0`, `1`, and `2`.

The card image and first thumbnail use `assets/batchz1.png`; the next
thumbnails use `assets/batchz2.png` and `assets/batchz3.png`. The
`projectImages.batchzone` array must use the same three paths and order.

Keep the existing Batchzone title, description, placeholder project link, and
shared lightbox behavior.
