# Basic-SocMed Code Specification

Basic-SocMed is the second `.project-card` in the Projects section and uses
`data-project="basicsocmed"` with indices `0`, `1`, and `2`.

The card image is `assets/feeds.png`. The visible thumbnails use
`assets/socmed1.png`, `assets/socmed2.png`, and `assets/socmed3.png` in order.
The `projectImages.basicsocmed` array currently uses the feed screen followed
by the two gallery screens, and must stay synchronized with the visible
thumbnail indices when changed.

Keep the existing placeholder project link, description, and alert behavior.
