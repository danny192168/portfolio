# Cat-bolz Code Specification

The Cat-bolz project is the first `.project-card` in the Projects section of
`portfolio_danny.html`. Its markup uses `data-project="catbolz"` and indices
`0`, `1`, and `2`.

The card image and first thumbnail use `assets/catz1.png`. The remaining
thumbnails use `assets/catz2.png` and `assets/catz3.png`. The
`projectImages.catbolz` array near the end of the inline script must contain
those same paths in that order so the lightbox matches the clicked thumbnail.

Keep the existing Cat-bolz title, Firebase link, description, thumbnail
classes, and accessible alt text unless the task specifically changes them.
